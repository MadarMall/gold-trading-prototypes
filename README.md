# پروتوتایپ‌های اپ معاملات طلا

سه پروتوتایپ تعاملی موبایل برای اپ معاملات طلای آبشده، ویژهٔ طلافروش‌ها و کارگاه‌دارها:

1. **تابلوی زنده**: تیره و پرتراکم، با قفل قیمت و «بکشید تا ثبت شود».
2. **پیشخوان**: روشن، معامله داخل همان کارت نرخ.
3. **دستیار معاملات**: تابلوی نرخ ثابت، به‌علاوهٔ ثبت سفارش با جملهٔ فارسی یا صدا.

صفحه: https://madarmall.github.io/gold-trading-prototypes/

نام و نشان برند موقت است و قیمت‌ها نمونه هستند و زنده شبیه‌سازی می‌شوند. کل صفحه در `index.html` است و به هیچ build یا وابستگی نیاز ندارد.
